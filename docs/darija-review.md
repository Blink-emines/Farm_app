# Darija review (Arabic script)

Written for a native Darija speaker. The farmer screens in `frontend/src/i18n/ar.js` were rewritten from standard Arabic into Darija. The Details (for advisors) tab and the all-fields optimiser stay in standard Arabic.

How to fix one: edit the value of that key in `frontend/src/i18n/ar.js`, or write the correction in the last column and give this file back.

## Words used throughout

- فدّان (field, plot), plural الفدادن: used everywhere instead of حقل
- الشتا (rain), الما (water), ناشف (dry), الجّليد (frost)
- زرع / حصد (sow / harvest), الزريعة (seed), الصّابة (harvest, yield), المردودية (return)
- دابا (now), شنو / كيفاش / فين / شحال (what / how / where / how much)
- Month names: Moroccan forms (يناير … دجنبر), unchanged.
